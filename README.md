# 🔧 Mechanical Maintenance & Technical Logs

Repositori ini adalah dokumentasi teknis digital untuk seluruh aktivitas perawatan, perbaikan, dan modifikasi mesin yang saya lakukan secara mandiri. Sebagai siswa DKV yang juga seorang mekanik, saya menerapkan standar dokumentasi yang rapi untuk setiap pekerjaan hardware.

### 🛠️ Spesialisasi Teknis
*   **Engine Overhaul & Tuning**: Melakukan bongkar pasang komponen internal mesin untuk menjaga performa optimal.
*   **Electrical Troubleshooting**: Analisis sistem pengisian, modifikasi spul/stator (rewinding), dan perbaikan kelistrikan bodi.
*   **Fuel System Maintenance**: Pembersihan Throttle Body, pengecekan Fuel Pump, dan optimasi sistem injeksi.
*   **Precision Adjustment**: Pengaturan celah katup (valve clearance) dan komponen presisi lainnya.

### 🏍️ Unit Riset Utama
- **Model**: Yamaha R15 V2[cite: 1].
- **Fokus**: Durabilitas mesin untuk penggunaan harian dan efisiensi sistem kelistrikan[cite: 1].

### 📝 Mengapa Dokumentasi Ini Penting?
Saya percaya bahwa ketelitian dalam menangani hardware mesin sama pentingnya dengan ketelitian dalam menulis kode atau mendesain visual. Repositori ini menunjukkan kemampuan problem-solving saya secara sistematis di dunia mekanik[cite: 1].
